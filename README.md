# Brunella Outlet - Tienda Online de Accesorios de Plata 925

Este proyecto de la cursada de Front End JS **Brunella Outlet**, es para un emprendimiento especializado en la venta de accesorios de Plata 925.

## Requisitos de la Pre-Entrega Cumplidos
- **Estructura Semántica de HTML5:** Distribución modular mediante `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
- **Navegación Interna Coherente:** Creación de enlaces relativos (`index.html` y `pages/contacto.html`) ida y vuelta, sin fallos de rutas.
- **Formulario de Contacto Funcional:** Vinculado con Formspree para la captación directa de mensajes de clientas.
- **Diseño Responsivo con CSS3:**
  - **Flexbox:** Organiza y adapta de manera fluida las tarjetas de los productos.
  - **CSS Grid:** Modula de forma estética la cuadrícula de opiniones y testimonios de las clientas.
  - **Media Queries:** Garantiza que la página y el header se adapten a los dispositivos.
- **Tipografías y Estilos:** Importación de Google Fonts ("Playfair Display" para títulos y "Montserrat" para textos), además de la aplicación de propiedades avanzadas de backgrounds.
- **Multimedia Local:** Integración de imágenes originales y un video en formato de historia.
